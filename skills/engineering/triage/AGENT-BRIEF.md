# Writing agent briefs

An agent brief is a tracker comment pointing to the authoritative issue or PR body. Post it when applying an approved ready outcome. For an external PR with a governing issue, link that issue body; otherwise link the PR body. If an old brief still looks current, identify it as historical in the pointer comment.

```markdown
> *This was generated by AI during triage.*

## Agent Brief

**Specification:** <link to the authoritative issue or PR body>
**Verification:** <observed result and evidence links, or "not verified">
**Constraints:** <known limitations or non-blocking questions; omit when none>
```

Record why human action is needed for `ready-for-human`. Keep scope and acceptance criteria in the body, not the comment. If verification exposes missing or conflicting requirements, resolve those through the [issue-body guide](ISSUE-DESCRIPTION.md) before marking the work ready.
